# 공간좌표 입체 강의 (기하 III-2)

미래엔 기하 교과서 III단원의 두 번째 중단원 **공간좌표**를 three.js 입체 강의로 만든 것입니다. 「공간도형」과 같은 엔진·방식입니다. 문장과 수식은 두께 있는 3D 글자로 양쪽 벽에 서고, 가운데에는 교과서 TikZ 그림(좌표축·좌표 상자·구)을 3차원으로 옮긴 그림이 단계마다 바뀝니다.

## 구성 (61단계, 영상 약 20분)

| 소단원 | 내용 |
|---|---|
| 1 점의 좌표 | 좌표공간·좌표평면 · 점의 공간좌표(보기) · 두 점 사이의 거리(보기) · 예제 1 · 생각 넓히기(최솟값) |
| 2 선분의 내분점과 외분점 | 내분점의 좌표(정사영으로) · 내분점·중점·외분점 공식(보기) · 삼각형의 무게중심 · 생각 넓히기(사면체의 무게중심) |
| 3 구의 방정식 | 구의 방정식(보기) · 예제 2 · 이차방정식이 나타내는 구 · 예제 3 |
| 중단원 마무리 | 16문항 |

- **개념 · 보기 · 예제**: 그림과 함께 단계별 풀이와 해설. **문제 · 생각 넓히기 · 중단원 마무리**: 문제와 그림만, 5초 멈춤.
- 교과서 그림의 축 배치(수학 좌표 (x, y, z) → TikZ (y, z, x): x축 앞, y축 오른쪽, z축 위)를 그대로 따릅니다.
- 원문의 오류를 고쳐 실었습니다: 두 점 사이의 거리 유도에서 P(x₁, y₂, z₁), Q(x₂, y₂, z₁)이면 AP = |y₂ − y₁|, PQ = |x₂ − x₁|, QB = |z₂ − z₁| 입니다(원문은 AQ, BP 로 잘못 씀).
m P(x_1,y_2,z_1)$, $
m Q(x_2,y_2,z_1)$이면 $\overline{
m AP}=|y_2-y_1|$, $\overline{
m PQ}=|x_2-x_1|$, $\overline{
m QB}=|z_2-z_1|$ 입니다.

## 파일

| 파일 | 내용 |
|---|---|
| `content.js` | 단계 내용: 블록(교과서 한 덩어리)마다 벽 글(`L`), 큰 수식(`big`), 해설 대본(`say`), 그림, 멈춤(`hold`) |
| `figs.js` | 그림 모음: TikZ 좌표 그대로 점·선분·평면·면·직각 표시·각·같은 길이 표시·원·구·원기둥 |
| `index.html` | 엔진(latex2three3d 템플릿 + 위 두 파일에서 단계·글·카메라·그림을 만든다) |

벽에 글이 다 들어가지 않으면 새 쪽으로 넘어가고, 그림은 블록이 바뀔 때마다 그려졌다 사라집니다.

## 조작

- → / Space: 다음, ←: 이전, Home: 처음부터 · 아래 점을 누르면 그 단계로
- 끌기: 회전, 휠: 확대·축소, 오른쪽 끌기: 이동, 두 번 클릭: 원래 시점
- 위쪽 버튼: 🔊 음성 켜기·끄기, 자동 재생(문제 단계는 해설 뒤 5초 더 멈춤), 처음부터
- 시험용 주소: `?step=N`, `?mute`

## 해설 음성

Azure `ko-KR-HyunsuMultilingualNeural`. 대본은 `content.js` 의 `say` 입니다. 고친 뒤 `python make_voice.py`(바뀐 것만) 또는 `--all`.
환경변수 `AZURE_SUBSCRIPTION_KEY`, `AZURE_SERVICE_REGION` 이 필요하며 키는 페이지에 들어가지 않습니다.

## 영상 만들기 (4K 60fps)

```
node record_all.mjs      # 단계마다 따로 녹화(seg/) → video_noaudio.mp4  (크롬이 중간에 멈추면 그 단계만 다시, 다시 실행하면 이어서)
python mix_audio.py      # 해설 + 배경음악 + 자막 → 공간좌표_4K.mp4, 공간좌표_4K.srt
```

- 단계 길이 = 앞 여유 1초 + 해설 + 멈춤(문제 5초) + 끝 여유 1.6초. 멈춤은 페이지의 `HOLDS` 에서 읽습니다.
- 자막은 해설 대본에서 만들며, 소리 나는 대로 쓴 글자 이름을 기호로 바꿉니다(에이비 → AB, 피 프라임 → P′).
- 크롬, ffmpeg, Node 18 이상, Python(numpy, scipy)이 필요합니다. 이 PC에서 4K 녹화는 약 5~6시간 걸립니다.
